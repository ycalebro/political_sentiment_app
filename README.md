An end-to-end sentiment analysis tool that compares cross-community political discourse on Reddit. 

The app fetches public discussions from political subreddits (such as `r/Conservative` and `r/democrats`), runs natural language processing (VADER) to evaluate sentiment toward target entities (e.g., *Trump / MAGA* vs. *Democrats*), and renders an interactive analytics dashboard.

---

## 💡 Why This Project?

API restrictions often make scraping social web data frustrating or fragile. This project demonstrates a keyless data collection pipeline using public RSS endpoints—bypassing rate-limit wall blocks without requiring OAuth credentials—coupled with a decoupled architecture that separates the data ingestion engine from the visual frontend.

---

## ✨ Features

- **Keyless Data Extraction:** Scrapes live posts from Reddit's RSS feed without needing API credentials or developer account approvals.
- **NLP Sentiment Engine:** Leverages VADER (Valence Aware Dictionary and sEntiment Reasoner) to compute compound sentiment scores on post text.
- **Entity Identification:** Categorizes posts based on entity mention keywords to compare sentiment context across target topics.
- **Interactive Dashboard:** Built with Streamlit and Plotly to visualize:
  - Average sentiment score per subreddit
  - Overall sentiment distribution histograms
  - Volatility and variance across subreddits via interactive Box Plots
  - Raw post data tables for spot-checking results
